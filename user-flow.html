AI Audience Builder — User Flow

One screen (chat + live preview), three entry points that interweave. This diagram shows structure and decision points — not visual mockups. Colors follow the Raptor design system only to distinguish scenarios.

AI assistance. Enters the chat + live-preview screen. Hosts Scenario 2 (suggestions) and Scenario 3 (free chat) together.

AI analyses the input

AI proposes an initial audience with sensible default assumptions shown as editable chips in the preview.

Is the input ambiguous? e.g. “plates” = dinnerware or vinyl? · buyers or browsers?
YES → clarify
CLARIFY · optional

AI asks a focused follow-up

Layer A — product: scope, which attributes matter, semantic expansions.
Layer B — audience: behaviour (buy vs visit), proximity threshold, time window.

Benefit: AI asks only what’s unclear — low effort for non-technical marketers.
NO → skip
SKIP

No question needed

AI keeps its default assumptions and goes straight to the live preview.

2 · LIVE

Live preview recalculates

Audience size, % of total population, criteria chips and reasoning update after every message. Changed values highlight.

Benefit: replaces manual “Save & Refresh” (static) with a live preview — user sees the audience form in real time.
↻ Loop: user sends another message → clarify (only if needed) → preview updates again.
